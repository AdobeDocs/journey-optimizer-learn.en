# Edit and personalize section content

Edit and personalize individual sections of an email template with AI capabilities in Adobe Journey Optimizer. Change subject lines, preheaders, text blocks, and images while preserving brand colors, voice, and compliance rules. Use prompts and reference content to adjust tone, rephrase text, translate language, and generate on-brand visuals for each component.
